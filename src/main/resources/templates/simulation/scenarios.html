Diferencia entre reloj global, escenario y concurrencia real
  • Ámbitos de reloj: el reloj lógico global mantiene la monotonicidad del sistema entre reinicios; cada escenario tiene su propio reloj (inicia en t=0) para programar eventos sin retroceder el reloj global.
  • Eventos discretos vs. concurrencia multihilo: esta pantalla ejecuta eventos secuenciales deterministas (1 paso a la vez) para estudiar políticas y colas; la concurrencia real entre hilos simultáneos se protege mediante bloqueos pesimistas SELECT ... FOR UPDATE (ADR-0002) y se demuestra con las pruebas de integración multihilo.
