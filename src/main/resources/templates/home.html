ARE — Arequipa RescUE

Simulador académico de atención de emergencias médicas, despacho concurrente de ambulancias, cálculo de rutas mediante Dijkstra sobre una red vial simplificada de Arequipa y gestión simulada de capacidad hospitalaria.

Arquitectura y base técnica

Estilo arquitectónico
Monolito modular con principios de arquitectura hexagonal y presentación Spring MVC + Thymeleaf
Base técnica activa
Java 21 LTS, Spring Boot 3.4.5, MySQL 8.4 LTS (Flyway), grafo inicial N01–N10 y reloj lógico monotónico (t >= 0)
Sistema visual
Bootstrap 5.3.3 local, CSS de identidad ARE y Lucide Icons 0.469.0 sin dependencias externas en ejecución
